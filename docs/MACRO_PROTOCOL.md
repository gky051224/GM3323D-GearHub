# GM3323D 键盘宏与按键映射

日期：2026-10-25。目标接口和产品匹配条件与灯光、DPI 相同：产品名 GM3323D，VID/PID `1D57:FA60`，UsagePage `000B`，Feature 最大长度 132。仅独立实现协议；不分发原厂 EXE 或 DLL。

## 写入顺序

所有方案先完整校验，再激活默认配置 `0C 04 01 05`，等待 550 ms。发送标准按键映射、等待 550 ms，然后上传所选宏，每次间隔 550 ms，最后写入带宏绑定的按键映射。只允许后侧键、前侧键、顶部 DPI 键；新宏默认未绑定。取消或写入失败会停止后续步骤。

该过程不是原子操作，失败时可能已切换到配置 1 或恢复标准按键。无法读取并合并既有自定义映射，所以应用会替换该组完整映射。恢复默认按键同样先激活配置，再写入标准映射；它解除映射，不清除宏槽中的旧数据。

## 129 字节宏报告

| 偏移 | 内容 |
|---|---|
| 0–1 | `09 81`：报告 ID 与长度 |
| 2 | 宏槽：配置 1 的后侧键 4、前侧键 5、顶部 DPI 键 6 |
| 3 | `00`：有限次数模式 |
| 4–6 | `00 00 00`，保留原厂默认元数据值，具体含义未确认 |
| 7 | 重复次数 1–255 |
| 8–27 | 预留为零 |
| 28 | 打包后的动作槽数量，最大 50 |
| 29–128 | 每槽两个字节：延迟与方向，USB HID 键码 |

普通动作的第一字节低 7 位为延迟毫秒数除以 2；松开时置高位 `80`。第二字节是 USB HID 键盘用法码，例如 A=`04`、F13=`68`。允许 0–254 ms 偶数延迟。

延迟超过 254 ms 时，拆成余数和 200 ms 倍数：先写普通动作（余数），紧接一个扩展槽 `[倍数,03]`。最多 20 个扩展槽；扩展槽也计入 50 槽容量。应用限制延迟 0–10000 ms 的偶数，不静默舍入手工输入。所有按下必须有对应松开，结束不能留下按住的键。

后侧键一次 F13，按下和松开各 50 ms 的关键字段：

```text
09 81 04 00 00 00 00 01 … [偏移 28] 02 19 68 99 68 …
```

**顺序必须是延迟在前、键码在后。** 实机测试发现写反会产生错误键码。最终实现与原厂序列化函数的逐字段行为核对，后侧键 F13 已捕获实际按下和松开。

## 77 字节按键报告

起始 `08 4D 01`，其后 12 个三字节按键记录；剩余字段置零。标准记录的功能值依次为：

```text
02 03 04 05 06 0D 0E 0F 00 00 09 0A
```

每个功能值后跟两个零。索引 0/1/2 分别为左键、右键和滚轮点击；索引 3/4/5 为后侧键、前侧键和顶部 DPI 键。宏记录为 `[12,00,宏槽]`，这里 `12` 为十六进制、十进制 18。槽号与宏报告偏移 2 一致。

## 验证范围

用户授权临时后侧键测试后，经实际应用按钮上传并绑定。仅接收该 GM 接收器的 Raw Input 监听捕获 VK_F13=`124` 的按下与松开。测试后恢复标准按键，不保存临时宏或默认绑定。

前侧键、顶部 DPI 键、组合键、重复和长延迟的所有组合尚未逐一实测；不将离线编码测试等同于完整硬件验证。当前只支持有限次数键盘宏，不支持鼠标动作、无限循环或设备宏回读。详细记录见 [VALIDATION.md](VALIDATION.md)。
