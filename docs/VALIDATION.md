# GM GEAR 验证记录

日期：2026-10-25。针对新软件；原 GM3323D / 蓝牙耳机电量查看器保持独立。

## v0.3.0 宏适配

- 63 项协议与 WPF 界面检查通过。新增覆盖报文布局、长延迟扩展、按下松开配对、容量与重复次数边界、重复触发键冲突、默认未绑定、写入顺序、取消后不绑定、草稿保存、窗口内录制与离线预览不写设备。
- 用户明确要求不默认绑定。所有新宏初始为“未绑定”，保存、启动、重连不应用。录制只在应用窗口内处理按键，Esc、失去焦点或切换页面会停止，并补齐录制中未松开的按键。
- 用户明确授权临时使用后侧键测试 F13。最初没有捕获到预期按键；增加仅针对 GM 接收器的 Raw Input 诊断后发现错误按键。对照原厂序列化指令修正了每个动作的两个字节：先延迟与方向、后 USB 键码，扩展延迟同样按此顺序。
- 修正后的真实 UI 应用测试捕获 `GM RECEIVER KEY 124 DOWN` 和 `GM RECEIVER KEY 124 UP`（Windows VK_F13）。不是模拟键盘输入，也不是仅依据 SetFeature 成功推断。该次实机测试共 49 项检查通过。测试完成后发送标准按键映射，后侧键恢复后退，未保留默认绑定；临时宏没有写入用户草稿文件。
- 采用设备第 1 组默认配置，应用会写入完整的 12 键映射，未绑定的按键恢复标准功能。当前不能读取并保留原厂已有的自定义映射；界面显示此限制。
- 宏文件和界面可编辑保存；设备写入前检查按键配对、动作槽容量、0–10000 ms 偶数延迟、1–255 次有限重复与触发键冲突。先取消映射，再上传宏，全部成功后才绑定。中途故障可能已切换配置或恢复标准按键；不宣称原子更新。
- 实机确认范围为后侧键触发一次 F13。前侧键、顶部 DPI 键、组合键、长延迟、重复执行的全部组合尚未逐一实测。当前不支持鼠标动作、无限循环、宏或按键配置回读。
- `--live-macro <folder>` 为显式硬件测试：临时绑定后侧键发送一次 F13，最多等待 180 秒，并在 finally 中恢复标准按键。普通 `--ui` 完全不访问设备。

## v0.2.0 灵敏度适配

- 45 项协议与 UI 检查通过，涵盖 DPI 传感器编码、X/Y 镜像、高 DPI 倍率、参数边界、激活顺序、取消和失败短路、独立回报率、档位事件与电量事件区分；界面包含数值验证、档位卡片、合法步进与最低窗口尺寸。
- 最初仅发送 50 字节 DPI 指令，系统返回接受，但用户报告没有速度变化。补齐原厂的 `0C 04 01 05` 激活默认配置步骤及等待后，再发送 400 DPI 测试，用户明确确认“明显变慢了”。30 秒后脚本自动恢复 1200。
- 最终 C# 实机 UI 测试通过真实 ApplyButton 发送激活与 1200 DPI 方案；独立回报率按钮发送激活与 500 Hz，系统均接受。
- 这次验证没有用物理尺测量实际 CPI，也没有测量 USB 报告频率。不能将系统接受 500 Hz 指令等同于实测频率为 500 Hz。
- 当前未实现可靠的 DPI 设置回读，UI 明确标注本机方案。实机监听期间没有收到档位事件；事件解析有离线覆盖，但本固件主动推送能力尚未确认。不会从电量或缓存推导“实测 DPI”。
- DPI 应用目标为设备第 1 组默认配置，替换六档 DPI 及其指示色；不发送按键/宏设置。切换配置也会启用该配置原有的其他参数。
- `--live-dpi <folder>` 为会发送设备设置的显式实机测试，选择 1200 DPI 并应用 500 Hz；普通 `--ui` 不访问设备。

以下为历史验证记录；历史版本的“未实现 DPI”不代表当前版本。

## 灯光故障与修复

首版要求 GetFeature(0x04) 返回以 `05 0D` 开头的 132 字节配置，否则拒绝发送。实际读取的是连续设备描述与机器码，不能作为当前灯光配置。导致界面可以预览，实际应用总被拦住。

核对原厂程序的调用参数，确认灯光为独立的 13 字节 SetFeature(0x05) 指令。实机发送 `05 0D 01 01 04 08 46 D3 FF 06 01 00 00` 后，用户明确确认“已变成青色常亮”。没有发送 DPI、按键或宏指令。

## 已验证

- 24 项协议与 WPF UI 检查：电量事件解析、离线清空、未知状态；与实测成功报文逐字节一致；模式/RGB/亮度字段；关闭灯光编码；参数范围；预先取消不发送；系统拒绝时报告错误。
- 原生 WPF 界面：主页进入灯光页、颜色预设、亮度绑定、非法 HEX 禁用应用、预览不写入；DPI / 按键页面明确标注未适配；1040×720 最小窗口下应用按钮保持可用。
- 本机真实 GM3323D：确认产品名、UsagePage 000A 的 5 字节电量接口、UsagePage 000B 的 132 字节灯光接口。
- 使用新 C# 原生监听器收到本机真实鼠标电量 90%；这是实测结果，独立于 UI 示例数据。
- UI 导出的 80% 预览图明确标注为示例，不能当作实时硬件结果。
- 显式实机 UI 测试：真实接收器被检测，实际点击 ApplyButton，后台 FeatureSession 向设备发送青色常亮；界面反馈“已发送”。测试窗口中的电量为实时 90%。截图：`gear-live-lighting.png`。
