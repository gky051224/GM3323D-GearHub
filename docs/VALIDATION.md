# GM GEAR 验证记录

日期：2026-10-25。针对新软件；原 GM3323D / 蓝牙耳机电量查看器保持独立。

## 已验证

- 30 项检查：真实报文格式、在线与离线、越界与未知状态；132 字节 read-modify-write 五字段变更、其余 127 字节保留；取消后不写入；无有效配置不写入；设备拒绝写入不宣称成功。
- 原生 WPF 界面：主页进入灯光页、颜色预设、亮度绑定、非法 HEX 禁用应用、预览不写入；DPI / 按键页面明确标注未适配；1040×720 最小窗口下应用按钮保持可用。
- 本机真实 GM3323D：确认产品名、UsagePage 000A 的 5 字节电量接口、UsagePage 000B 的 132 字节灯光接口。
- 使用新 C# 原生监听器收到本机真实鼠标电量 90%；这是实测结果，独立于 UI 示例数据。
- UI 导出的 80% 预览图明确标注为示例，不能当作实时硬件结果。

## 尚未验证

- 点击灯光应用后的实际硬件变化、不同模式与颜色完整矩阵。
- 不同固件的 Feature 首字节约定；提供默认原样格式和可选 ID 前缀格式。
- 有线与充电状态、完整放电过程、不同显示器的全部 DPI 组合。
- DPI、回报率、按键与宏控制尚未实现。

启动只读监听，不自动写配置；测试未调用真实灯光写入。软件提示接口接受时，表示 SetFeature 调用成功，仍需通过鼠标灯光确认效果。
