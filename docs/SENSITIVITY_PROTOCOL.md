# GM3323D DPI / 回报率协议

日期：2026-10-25。目标为本机无线 GM3323D（1D57:FA60、产品名 GM3323D、UsagePage 000B、最大 Feature 132），Windows `HidD_SetFeature`。字段与顺序通过本机原厂程序调用参数核对；只独立实现协议，不分发原厂程序或 DLL。

## 必须先激活默认配置

```text
0C 04 01 05
```

4 字节，选择设备配置组 1。原厂在配置激活后等待约 500 ms；本实现等待 550 ms，然后发送 DPI 或回报率。取消或激活失败会中止后续发送。所有参数先验证，再激活配置。激活与后续写入不是原子操作，中途失败可能已切换配置，应报告未完成并重试。

仅发送 DPI 报告时，系统接受但用户报告没有变化。加入激活步骤后，400 DPI 测试得到“明显变慢了”的实机确认。这是最终流程的必要步骤，不可仅靠 SetFeature 返回值判断硬件效果。

## DPI 报告：50 字节

默认六档 800 / 1200 / 1600 / 2400 / 3200 / 5000，选择 1200：

```text
04 32 01 08 08 3F 00 00 12 1B 24 37 49 73 00 00
12 1B 24 37 49 73 00 00 02 FF 00 00 00 FF 00 00 00
FF 00 FF FF FF FF 00 FF 00 FF FF FF FF FF FF FF 01
```

| 偏移 | 内容 |
|---|---|
| 0–2 | ID 04，长度 32，配置组 01 |
| 3–4 | 原厂方案固定 08 / 08 |
| 5 | 档位启用位图 3F，启用前六档 |
| 6–7 | X/Y 高 DPI 倍率位图，每档一位 |
| 8–15 | 8 档 X 轴传感器编码；最后两档停用，填 00 |
| 16–23 | 对应 Y 轴编码，本实现与 X 相同 |
| 24 | 当前档位，从 1 开始 |
| 25–48 | 8 组 RGB 指示色：红/绿/蓝/青/黄/紫/白/白 |
| 49 | 固定 01 |

200–5000 DPI 以 100 为步进，通过原厂设备的传感器寄存器查表编码。高于 5000 时先除以 2 编码，同时设置两张倍率位图相应的位；因此 5200–10000 应使用 200 步进。5100 等不可精确编码值应拒绝或明确量化，不能显示 5100 却静默发送 5000。

应用会替换设备配置组 1 中的六档 DPI 和指示色。不会修改 Windows 指针速度，不发送按键或宏指令。由于需要激活配置组，该组其他既有参数也会成为当前活动参数。

## 回报率报告：9 字节

```text
06 09 01 RR 00 00 00 00 00
```

`RR`：125 Hz → 08，250 Hz → 04，500 Hz → 02，1000 Hz → 01。回报率与 DPI 单独应用，同样先激活默认配置。

## 回读与验证边界

当前没有可靠的设置回读；不使用 GetFeature(04,132) 的连续内存块冒充当前 DPI。设备档位事件如 `03 00 10 02 00` 可表达第 2 档，与电量事件分开解析；本次监听没有捕获实际档位事件，解析器有离线测试，不能假定所有固件都主动推送。

已经通过界面发送 1200 DPI 方案与 500 Hz 指令。400 DPI 的速度变化经用户确认，但没有用物理尺测量 CPI，也未测 USB 实际回报频率；其余完整数值组合和不同固件仍待测试。
